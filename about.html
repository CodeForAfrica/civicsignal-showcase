CivicSignal · About Code for Africa · Since 2012

Understanding Africa's digital democracies.

CivicSignal is Code for Africa's research and analysis programme — actionable insight into Africa's media ecosystem and emerging civic technology sector, built by human experts using machine learning and 'big data' resources, not replacing that judgement with them.

Who's behind this

Code for Africa: the continent's largest network of civic technology and data journalism labs.

Founded in 2012 by Justin Arenstein, Code for Africa (CfA) is a pan-African federation of civic data and civic technology organisations, registered in South Africa with teams working across some 20 African countries. Its own description of its mission: "CfA builds digital democracy solutions that give citizens unfettered access to actionable information that empowers them to make informed decisions, and which strengthens civic engagement for improved public governance and accountability."

Beyond CivicSignal. CfA's wider portfolio includes PesaCheck and the African Fact-Checking Alliance (fact-checking), openAFRICA and sourceAFRICA (open-data portals), ANCIR (forensic and digital-security support for investigative newsrooms), academy.AFRICA (journalist training), and africanDRONE and sensors.AFRICA (civic sensing).
The wider network

The Plus Alliance: pooling capacity across civic tech, journalism and media research.

Code for Africa doesn't build this alone. The Plus Alliance was co-founded by Code for Africa, the International Center for Journalists and PROTO in 2024, joined by the European Journalism Centre as a constituent member in June 2026 — bringing EJC's own long-running medialandscapes.org lineage into what MediaScapes draws on. Registered in South Africa, the Alliance operates from Cape Town, Delhi, Doha, Maastricht, Nairobi and Washington, DC.
